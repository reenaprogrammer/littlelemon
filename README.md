# 🍋 Little Lemon Restaurant Reservation Application

A modern, responsive, and accessible table booking web application built with React for the Meta Front-End Developer Capstone project.

## 🚀 Features
- **Multi-Page Navigation:** Client-side routing using `react-router-dom` (Home, Booking, and Confirmation pages).
- **Controlled Reservation Form:** Table booking system with state management handled via React `useReducer` and `useState` hooks.
- **Client-Side Validation:** Real-time validation checks to prevent booking past dates, invalid time slots, or incorrect guest counts.
- **Accessibility (WCAG) Compliance:** Built using semantic HTML tags and explicit `aria-*` attributes for screen readers and assistive devices.
